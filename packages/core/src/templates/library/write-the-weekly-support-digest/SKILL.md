# Write the weekly support digest

## What to do

1. Read the week. Group into themes by what the customer was trying to do.
2. For each theme: the count, one verbatim customer sentence, and what would make it stop.
3. Order by count times how annoyed people were, not by count alone.

## Rules

- Quote customers verbatim. A paraphrase loses the thing that makes someone act.
- Five themes maximum. Anything longer is a spreadsheet, not a digest.
- A quiet week gets three lines.
