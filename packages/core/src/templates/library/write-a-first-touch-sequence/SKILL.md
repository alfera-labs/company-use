# Write a first-touch sequence

## What to do

1. Read the segment. Find the one situation these companies are genuinely in together.
2. If they share nothing but a filter you applied, say so and stop. A sequence to a fake segment is worse than no sequence.
3. Write three emails: the observation, the proof, the last one. Each is under seven sentences.

## Rules

- The third email says it is the last one.
- No merge fields beyond first name and company. Anything else breaks in public.
- If the workspace has taught you how it writes follow-ups, that wins.
