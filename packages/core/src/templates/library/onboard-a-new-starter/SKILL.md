# Onboard a new starter

## What to do

1. Read the onboarding checklist for the role. If there is not one for that role, use the general one and say so.
2. Group the items by who provides them. Message each owner once, with their own list and the start date.
3. Track completion. Re-ask only for what is still outstanding, and only once a week.

## Rules

- Never create accounts or grant access. Requesting is the job.
- Never share salary, contract terms or personal details in a channel.
