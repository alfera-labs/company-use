# Code of conduct

This project is a place to build software together. These rules apply in issues, pull
requests, discussions, and every other project space.

## What we expect

- Be respectful. Disagree with the idea, not with the person.
- Be clear and kind in review. Say what to change and why.
- Assume good intent, and ask before you assume the opposite.
- Keep it about the work.

## What we do not accept

- Harassment, insults, or personal attacks.
- Discrimination of any kind.
- Publishing someone's private information.
- Sexual language or imagery, and unwelcome attention.

## Reporting

Write to security@alfera.ai, the same private inbox the security policy uses. We read every
report, we keep it private, and we answer within five working days.

## What happens next

The maintainers can remove a comment, close a thread, or ban a person from the project. They
choose the smallest action that stops the problem.
